03. Projects

Featured Engineering Builds

Computer Vision & Algorithms

Vision-Based Autonomous Rubik’s Cube Solver

HSV colour segmentation and computer vision extract the cube state, which feeds Kociemba’s two-phase solving algorithm.

Applies automated HSV color thresholding under fluctuating room lighting to isolate facelet matrices, then generates minimal-move solution steps in sub-second compute time for robotic actuation.

OpenCV Python Kociemba Algorithm Robotics
Embedded Telemetry & Control

Real-Time Hand Gesture-Controlled Robotic Vehicle

MediaPipe and OpenCV send low-latency UDP commands over Wi-Fi to an ESP32 motor controller.

Tracks 21 hand landmarks in real time through a camera, maps physical spatial gestures to directional motor vectors, and transmits them with sub-20ms latency over a Wi-Fi UDP stream.

ESP32 MediaPipe OpenCV UDP / Wi-Fi
Autonomous Robotics

Lyra: Tennis Ball Detection & Trajectory Tracking Dog

HSV masking and contour-moment tracking with OpenCV to compute the centroid and trajectory in real time.

Autonomous robotic platform that isolates dynamic target objects in motion, calculates velocity vectors, and steers mechanical actuators to match the predicted intercept coordinates.

OpenCV Contour Moments Python Autonomous Steering
Android Architecture

Nseen: See Removed Texts

An Android event-listener service that intercepts, parses and caches notifications to recover deleted messages.

Runs a low-footprint background service listening to system notification broadcasts, caching message payloads into local SQLite before recall events execute.

Android SDK NotificationListener Java / Kotlin SQLite
